# MD-LIB

Bibliothèque de règles de travail réutilisables, écrites pour être **copiées**
dans le `CLAUDE.md` de chaque projet plutôt que référencées — voir
[`CLAUDE.md`](CLAUDE.md) pour le fonctionnement et la règle de propagation.

## Références communes à tous les projets

Désignées par l'utilisateur le 29/10/2026 pour les projets actuels et futurs,
et non pour GDINV2 seulement. Ces fichiers de MD-LIB sont les sources
canoniques à consulter pour le travail concerné :

| Référence | Objet |
|---|---|
| [archivage-cd47.md](archivage-cd47.md) | Conservation, tableau de gestion et archives publiques |
| [charte-ia-cd47.md](charte-ia-cd47.md) | Usage de l'IA, confidentialité et validation humaine |
| [charte-graphique-cd47.md](charte-graphique-cd47.md) | Identité visuelle et documents CD47 |
| [rgpd-securite.md](rgpd-securite.md) | Minimisation et sécurité des accès et des données |

Les trois résumés institutionnels renvoient aux PDF de référence, qui font
foi ; les PDF internes ne sont pas publiés ici. Une référence commune ne
rend pas les obligations institutionnelles CD47 applicables sans objet à un
projet personnel. Citer ces sources sans recopier leurs résumés dans chaque
projet ; consulter ses instructions locales avant toute intervention.
